# TripWire v2 (delegation-boundary version)

This directory extends the v1 release with the v2 code, data and analysis of the paper
"What Origin Checks Cannot See: Three Measured Boundaries of Provenance-Only Defenses for LLM Agents".

## Layout

| path | content |
|---|---|
| `tripwire_v2/tripwire_v2.py` | the v2 arms (coverage rules R1/R2b/AMB, hist, v2c) on top of v1's executor |
| `tripwire_v2/tripwire_agentdyn.py` | argument roles for the AgentDyn suites, fixed from signatures and docstrings only |
| `experiments_v2/EXPERIMENT_PLAN_rope.md` | pre-registration E1 (four models, AgentDojo suites) |
| `experiments_v2/EXPERIMENT_PLAN_v2.md` | pre-registration H1/E2X with all amendments |
| `experiments_v2/ANALYSIS_LOG.md` | every analysis bug, with fix time relative to first reporting |
| `experiments_v2/e_rope_run.py` | E1/H1 driver, all arms, inside ROPE's vendored harness |
| `experiments_v2/e_rope_e2x.py` | E2X driver (conditions a/b/c/a_h/c_h, hist and rope sensitivity arms) |
| `experiments_v2/e2x_tasks.py` | the frozen 40-task set (construction rules in the docstring) |
| `experiments_v2/e2x_prevalence.py`, `boundary_prevalence.py` | RQ4 censuses (delegation; synthesis and reception) |
| `experiments_v2/e2x_rope_scope.py` | ROPE scope cross-tab from the committed router cache |
| `experiments_v2/e1_verdict.py`, `v2_r0_check.py`, `v2_h1_decision.py` | registered decisions |
| `experiments_v2/e2x_analyze.py` | E2X summary and H2a/H2b tests |
| `experiments_v2/diag_e1_leaks.py`, `diag_h1_cu.py`, `dev_replay.py` | offline diagnoses (leak taxonomy, utility collapse, rule costs) |
| `analysis_v2/make_numbers_v2.py` | result files -> every number macro of the paper |
| `analysis_v2/tables_v2.py` | result files -> every table fragment of the paper |
| `data_v2/e1_rope/` | E1 raw logs (4 models x 4 arms x 446) |
| `data_v2/v2_heldout/` | H1 raw logs (3 models x 4 arms x 620) and the decision |
| `data_v2/e2x_*/` | E2X raw logs (5 conditions x 5 arms x 3 models + sensitivity arms) |
| `data_v2/e2x/router_cache.json` | the temperature-zero router scopes that produced the reported numbers |
| `data_v2/dev_v2/` | offline dev replay results |
| `data_v2/_superseded/` | archived mis-runs (see NOTES inside each) |

## Table-to-script map

| paper table | generated by |
|---|---|
| E2X grid (5x5) and per-model | `tables_v2.py` -> `tab/e2x_main.tex`, `tab/e2x_permodel.tex` |
| ROPE by router/audit verdict | `tables_v2.py` -> `tab/rope_scope.tex` (from `data_v2/e2x/rope_scope_xtab.json`, built by `experiments_v2/e2x_rope_scope.py`) |
| H1 per model | `tables_v2.py` -> `tab/h1_permodel.tex` |
| H1 blocked-call decomposition | `tables_v2.py` -> `tab/h1_blocks.tex` (from `data_v2/diag/h1_cu.json`, built by `experiments_v2/diag_h1_cu.py`) |
| Boundary census | `tables_v2.py` -> `tab/census.tex` (from the two prevalence scripts) |
| Every number macro | `analysis_v2/make_numbers_v2.py` |

## Reproduction sketch

1. Install as in the v1 README; clone ROPE at commit 64495e16 into `ext/rope` (not vendored).
2. `experiments_v2/e_rope_run.py` for E1/H1 arms, `experiments_v2/e_rope_e2x.py` for the grid.
3. `analysis_v2/make_numbers_v2.py && analysis_v2/tables_v2.py` regenerate every number in the paper from the frozen logs.

ROPE is third-party MIT-licensed code and is not vendored here.
